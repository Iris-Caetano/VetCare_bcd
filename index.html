01 / SOBRE O PROJETO

Uma solução para organizar a rotina veterinária

Uma clínica veterinária precisa manter informações de tutores, animais, profissionais, consultas e serviços. Quando esses dados ficam espalhados ou são registrados sem organização, pode ser difícil localizar informações e acompanhar os atendimentos.

O VetCare propõe um banco de dados relacional que conecta essas informações por meio de tabelas e relacionamentos, facilitando consultas, atualização e análise dos dados.

03 / CONSULTAS SQL

Transformando dados em respostas

As consultas SQL permitem buscar, filtrar, relacionar e resumir informações do banco.

INNER JOIN

Relacionar tabelas

Combina registros relacionados, como os animais e seus tutores.

SELECT a.nome, t.nome AS tutor
FROM animais a
INNER JOIN tutores t
  ON a.id_tutor = t.id_tutor;
WHERE + LIKE

Filtrar informações

Localiza animais de uma espécie específica ou tutores por padrão de nome.

SELECT nome, especie
FROM animais
WHERE especie = 'Gato';
GROUP BY + COUNT

Resumir resultados

Conta quantas consultas estão associadas a cada veterinário.

SELECT v.nome, COUNT(c.id_consulta)
FROM veterinarios v
LEFT JOIN consultas c
  ON c.id_veterinario = v.id_veterinario
GROUP BY v.id_veterinario, v.nome;

04 / ORGANIZAÇÃO DOS DADOS

Entendendo a normalização

As formas normais ajudam a estruturar tabelas e reduzir redundâncias. A conformidade precisa ser verificada pelas dependências dos atributos.

1FN

Valores atômicos

Cada campo armazena um valor por registro, sem listas de itens na mesma célula.

2FN

Dependência completa

Os atributos não-chave dependem da chave primária completa.

3FN

Sem dependências transitivas indevidas

Os atributos não-chave dependem da chave, não de outros atributos não-chave.

4FN

Dependências multivaloradas

Evita reunir conjuntos independentes de múltiplos valores na mesma tabela.
