# VetCare — Site do projeto acadêmico

Site institucional responsivo para apresentar o projeto VetCare, um banco de dados relacional para uma clínica veterinária.

## Arquivos

- `index.html`: conteúdo e estrutura das seções.
- `style.css`: cores, layout e adaptação para celular.
- `script.js`: menu responsivo e cartões interativos das tabelas.

## Como abrir

1. Extraia os arquivos da pasta compactada.
2. Mantenha os três arquivos na mesma pasta.
3. Abra `index.html` no navegador.

Não é necessário instalar bibliotecas para executar a versão básica. A fonte externa é carregada do Google Fonts; se não houver internet, o site usa fontes alternativas.

## Seções do site

- Apresentação do projeto
- Contextualização do problema e proposta de solução
- Descrição das oito tabelas
- Exemplos de consultas SQL
- Explicação introdutória das formas normais
- Situação das etapas do projeto

## Antes de entregar

- Confira se os nomes de campos e tabelas dos exemplos SQL correspondem ao seu banco real.
- Atualize o andamento do projeto quando a hospedagem Azure for concluída.
- Adicione ao repositório os scripts SQL, o dump e a imagem do modelo lógico, se isso estiver de acordo com as orientações do professor.
- Inclua no relatório uma explicação sobre a hospedagem em nuvem. Enquanto o Azure estiver pendente, não declare que o banco já está hospedado.
- Confirme as regras de normalização a partir das dependências funcionais de cada tabela.

## Publicação

O site pode ser versionado no GitHub. Para publicar, siga as orientações da atividade e escolha um serviço de hospedagem estática compatível, se permitido pelo professor.
